# Mario PPO Local LLM Integration

AI-powered analysis for Mario PPO training using local LLM models (Ollama).

## Overview

This project enhances the Mario PPO (Proximal Policy Optimization) training system with AI-powered analysis using locally-running LLM models. The integration allows the system to analyze training episodes, provide insights, and suggest hyperparameter adjustments using Ollama for efficient, local model serving.

## Key Features

- **Training Episode Analysis**: AI analysis of completed episodes at configurable intervals
- **Hyperparameter Suggestions**: AI-generated suggestions for improving training
- **Performance Insights**: Analysis of agent behavior and learning patterns
- **Local Processing**: Runs entirely locally using Ollama
